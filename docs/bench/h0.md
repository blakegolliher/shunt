# H0 benchmarks: data path unchanged, control-plane baseline captured

The H0 work (ADR-0021: T01, T02, T03, T07, then H0a–H0e) left the data path's benchmarks
statistically unchanged. The only significant changes are in the file directory's write path,
which is off the request path. This page also records the control-plane numbers the later slices
(H1–H5) compare against. Measured 2026-09-24.

## Method

- Host: AMD EPYC 7402P (24 cores, 16 visible), Linux 5.14.0-570.17.1.el9_6.x86_64, Go 1.27.1,
  `GOMAXPROCS` 16. The same host ran both sides, one after the other, never at once.
- Before: commit `91761de`, the last commit before the T-fixes and H0, checked out in a separate
  worktree. After: `59bfce4` (H0d) plus the H0e working tree, which made the lease read lock-free.
- `go test -run '^$' -bench . -benchmem -benchtime 1s -count 6` over the request-path packages:
  `internal/proxy`, `internal/sigv4/...`, `internal/s3/...`, `internal/upstream`,
  `internal/migrate`, `internal/directory`. Compared with benchstat at the Makefile's pinned
  version.
- Raw output: `test/bench/h0/datapath-91761de.txt`, `test/bench/h0/datapath-h0.txt`, and the
  comparison `test/bench/h0/datapath-benchstat.txt`.

## Data path: before and after

No benchmark in `internal/proxy`, `internal/sigv4`, `internal/sigv4/chunked`, `internal/s3`,
`internal/s3/s3response`, `internal/s3/xmlrw`, `internal/upstream` or `internal/migrate` changed
significantly (p ≥ 0.05 on every row). The per-package geomeans move by −5.3 % to +3.7 %, and each
of those moves sits within its rows' own run-to-run spread.

Significant changes, all in `internal/directory`:

| Benchmark | Before | After | Change | Why |
|---|---|---|---|---|
| `Create` time | 11.64 ms ± 5 % | 13.12 ms ± 10 % | +12.7 % (p=0.002) | a file-backend write now clones the previous file and stamps generations (`directory.Stamp`); the lab's write path, never a request |
| `Create` bytes | 1.136 MiB | 1.383 MiB | +21.7 % (p=0.002) | the same clone |
| `Create` allocs | 8,079 | 9,591 | +18.7 % (p=0.002) | the same clone |
| `ParseV2` bytes | 122.9 KiB | 122.9 KiB | +0.04 % (p=0.002) | the schema, identity and generations fields |
| `Scope64Rules` time | 467.1 ns ± 28 % | 410.1 ns ± 6 % | −12.2 % (p=0.041) | noise: the before side varied ±28 % |

## Control-plane baseline (after H0)

`go test -run '^$' -bench '<names>' -benchmem -benchtime 1s -count 6` over `internal/directory`,
`internal/control`, `internal/member`, `internal/cp` and `internal/upstream`. Raw output, with
embedded etcd's log lines removed: `test/bench/h0/control-plane-h0.txt`. Medians of six runs.

| Benchmark | What it is | Time | Memory | Allocs |
|---|---|---|---|---|
| `member.StaleParallel` | the lease check on the request path for moving buckets, 16 goroutines | 4.3 ns ± 5 % | 0 B | 0 |
| `upstream.RegistryLoadGet` | a request loading the cluster set | 13.2 ns ± 11 % | 0 B | 0 |
| `control.MemOperationsCreateUpdate` | one scoped operation's life in the lab store (create, start, end) with 1,000 ended records | 67.7 µs ± 15 % | 9.6 KiB | 15 |
| `cp.OperationsCreateUpdate` | one record created and ended on single-node embedded etcd, fsync included | 4.1–5.1 ms (six runs) | 49.5–50.2 KB | 526–530 |
| `member.Install` | one directory version of 1,000 placements: validate, prepare, publish, cache write with fsync | 12.5 ms ± 16 % | 2.18 MiB | 18.1 k |
| `directory.Stamp` | generation stamping of one write over 10,000 placements | 29.3 ms ± 11 % | 5.99 MiB | 60.1 k |
| `control.Status` | `GET /v1/status` read model | 463 µs ± 11 % | 172 KiB | 875 |
| `control.EventsPublish` | one event to the stream | 4.6 µs ± 17 % | 839 B | 8 |

The etcd operation store's results are shown as a range because etcd's logs interleaved with the
result lines, and benchstat could not group them.

`directory.Stamp` compares every resource on each write, at about 2.9 µs per placement. The control
node's existing `diff` already JSON-encodes every placement on each write, so stamping adds to a
write cost that is already proportional to the directory's size. The 100,000-placement budget of
design §8 is measured in H1 (T19), with this number as its starting point.

The lease read was a mutex in the T07 commit; H0e made it an atomic pointer to an immutable grant,
since `Stale()` runs on every request to a moving bucket.
